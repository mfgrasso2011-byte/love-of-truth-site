APPLICATION INFORMATION

New Covenant Sermon Publisher

A private publishing tool for authorized New Covenant OPC staff, operated by Michael Grasso.

The application helps staff prepare sermon descriptions, review the church’s YouTube broadcast schedule, and create or update approved broadcasts. Approved sermon descriptions and YouTube links can also be published to the church’s WordPress website and LoveOfTruth.net.

This page describes the publishing application. It is not a public sign-up service, and visiting this page does not connect a Google account or grant the application access to YouTube.

Google and YouTube access

Staff connect the intended church YouTube account through Google’s authorization screen. The application uses YouTube API Services to read channel and broadcast information and to create or update broadcast titles, descriptions, and scheduled times. Staff review and approve the publication details before the application makes publishing changes.

Read the application’s privacy notice for information about data use, storage, access revocation, and deletion requests.

Application use

This application is intended for authorized church staff managing the church’s own publishing workflow. The staff member is responsible for checking the selected account, source material, description, and schedule before approving publication.

The application uses YouTube API Services. Use of its YouTube features is subject to the YouTube Terms of Service. Google’s handling of information is described in the Google Privacy Policy.
